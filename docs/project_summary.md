# Project Summary

## Project Name

Texas Healthcare Workforce Access & Community Need Dashboard

## Objective

Build a Power BI dashboard that integrates public healthcare datasets to evaluate Texas county-level community health burden, workforce shortages, medically underserved designations, provider supply, and facility access context.

## Audience

This project is designed for portfolio review by healthcare analytics, quality improvement, business intelligence, population health, and workforce strategy audiences.

## Tools Demonstrated

- Power BI dashboard development
- Power Query data shaping
- DAX measures and calculated columns
- County-level public data integration
- Healthcare access and workforce analytics
- Dashboard storytelling and methodology documentation

## Data Sources

- CDC PLACES 2024 County Data
- HRSA HPSA Primary Care, Dental, and Mental Health data
- HRSA Medically Underserved Areas / Populations data
- HRSA Area Health Resources File county-level data

13. AHRF County Profile

## Core Analytic Themes

- Community health burden varies significantly across counties and measure categories.
- Shortage designations differ across primary care, dental, and mental health disciplines.
- Medically underserved designations provide additional context beyond provider shortage alone.
- Provider and facility rates per 10,000 residents help normalize county comparisons.
- County-level benchmarks support profile views that compare selected counties against Texas statewide context.

## Portfolio Value

This project demonstrates the ability to move from raw public healthcare datasets into a finished Power BI portfolio deliverable with clear data modeling, DAX calculations, interactive pages, documentation, and presentation-ready exports.
